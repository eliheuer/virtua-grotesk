# Google Fonts reference map

Core onboarding, QA, metadata, and article guidance refreshed on 2026-09-09.
Open only the references relevant to the task. Refresh them again when preparing
a submission; the guide and issue template can change independently of this repo.

| Topic | Official reference |
| --- | --- |
| Acceptance criteria and onboarding discussion | [Onboarding](https://googlefonts.github.io/gf-guide/onboarding.html) |
| Source layout, build recipe, and README | [Upstream structure](https://googlefonts.github.io/gf-guide/upstream.html) |
| Naming, license metadata, coverage, and features | [Font requirements](https://googlefonts.github.io/gf-guide/requirements.html) |
| Fontspector and visual proof review | [QA](https://googlefonts.github.io/gf-guide/qa.html) |
| Axes and variable-font requirements | [Variable fonts](https://googlefonts.github.io/gf-guide/variable.html) |
| Subsets, primary script, and source linkage | [Metadata](https://googlefonts.github.io/gf-guide/metadata.html) |
| Current About format and artwork | [Article](https://googlefonts.github.io/gf-guide/article.html) |
| Package creation and public source mapping | [Packaging](https://googlefonts.github.io/gf-guide/package.html) |
| Issue-before-PR and CLA requirements | [Making a PR](https://googlefonts.github.io/gf-guide/making-pr.html) |
| Current submission fields and attestations | [Add Font template](https://github.com/google/fonts/blob/main/.github/ISSUE_TEMPLATE/1_add-font.md) |
| Character-set definitions | [Glyphsets](https://github.com/googlefonts/glyphsets) |
| Optional repository template | [Project template](https://github.com/googlefonts/googlefonts-project-template) |

Use [the QA guide](../documentation/qa.md) for repository commands. Preflight
checks local artifact presence; it does not establish source freshness, full
QA success, human acceptance, or package readiness. Keep those conclusions
separate in [the onboarding checklist](../documentation/google-fonts/README.md).
