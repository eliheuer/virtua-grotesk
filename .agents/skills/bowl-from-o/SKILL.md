# Construct a bowl from o

Read [the design workflow](../../../design/README.md). Retrieve scoped context with
`.venv/bin/python scripts/design_context.py --glyph <name> --operation draw`;
repeat --glyph for a bounded group. Save a JSON packet before edits and verify it
immediately before applying. Read selected evidence, not the entire review archive.
Current scope and stopped work come from `design/reviews/current.json` and the user.

Read [the bowl construction](../../../design/constructions/bowls.md). Inspect the
live o and the relevant green b/d/p/q/g forms in each master before adapting.
Reuse exact round-half geometry, tangent relationships and contour order. Measure
current geometry; historical numeric examples are not constants for every weight.
Preserve the glyph's stem connection, counter, sidebearings, anchors and intentional
cuts. Follow edit-glyph/draw-outline and the selected verification contract.
