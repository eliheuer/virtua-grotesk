## Fixes made

- Set the OpenType WWS naming flag for this weight-only family and included
  Hebrew in the intended-script metadata. This removed five loose-font warnings.
- Compared every compiled table before/after: only `OS/2`, `meta`, and the
  `head` checksum/timestamp changed. Outlines, advances, layout, and variation
  tables are byte-identical. This was a metadata repair, not a glyph edit.
- Exposed full and package QA without development exclusions. Package checks
  receive metadata, license, and article inputs as well as fonts.
- Replaced contradictory release/docs placeholders with one onboarding checklist,
  one article draft, and one QA guide. CI now fails on QA failures, retains
  diagnostic artifacts, and does not publish releases automatically.

## Drawing and engineering blockers

1. **59 encoded visible characters have no outline** in the variable font:
   58 Hebrew characters and U+2010 HYPHEN. Empty default outlines are not cmap
   coverage. Resolve the exported blanks through the approved drawing workflow;
   do not remove Hebrew to suppress the finding.
2. **Contour and interpolation findings** include `quotesingle`,
   `uni0655064D`, `uni0651064B`, and `uni0651064C`. The compiler's structural
   compatibility report passes, but Fontspector flags point/contour order and
   weight behavior. These need visual review before source changes.
3. **Marks and shaping:** GDEF mark classification, accent/language shaping,
   outline direction, overlapping segments, and suspicious advance/sidebearing
   variation remain. U+200B ZERO WIDTH SPACE has advance 512 instead of zero.
4. **Network/package findings:** specimen text checks flag U+0331 and U+014B
   gaps, plus U+1EBD subsetting reachability. Some messages suggest sample-text
   data issues; reproduce and seek reviewer disposition rather than silently
   dropping languages or characters.
5. **Subset coverage:** the tool warns that `arabic` and `latin-ext` fall below
   its subset thresholds. These API subsets differ from the Core glyphsets.
   Keep the intended scope while deciding coverage work or a documented reviewer
   exception. The preview also flags unreachable codepoints.
6. **Submission materials:** the designer-profile lookup reports no profile,
   and the article has no visual asset. Confirm the existing designer identity
   with the onboarding team and prepare licensed artwork. Do not invent a new
   profile or grant an image license without the maintainer's approval.
