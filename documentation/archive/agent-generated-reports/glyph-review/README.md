# Glyph Review

This directory is the shared drawing and visual-review workspace for Virtua
Grotesk across scripts. Arabic review files currently dominate because Arabic
is the active drawing queue, but this is not a separate add-on track.

Use this area for Latin, Hebrew, Arabic, and cross-script drawing work when the
task is about outline quality, rhythm, spacing texture, mark behavior, proof
review, or manual edit queues.

Subdirectories:

- `contour-cleanup/` stores generated contour and source-edit review packets.
- `review-snapshots/` stores visual snapshots used by drawing review reports.
