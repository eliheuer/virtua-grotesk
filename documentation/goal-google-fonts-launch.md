# Italic proposal

This is a proposal, not an active execution instruction. The current build
contains only the upright family. Confirm whether Italic belongs in the first
release before adding sources or changing the release scope.

The proposed extension is a separate Italic variable font over wght 400–700,
with compatible Regular and Bold masters within that style.

## Open design decisions

- Corrected oblique or a separately drawn cursive italic.
- Slant angle. The earlier proposal suggested 10 degrees; this is not approval.
- First-release requirement or a later addition.

If approved, plan the drawing, spacing, build configuration, style linking,
proofing, and packaging together. Verify current Google Fonts requirements
when preparing that work. The upright worklist remains in
[the release checklist](google-fonts/README.md).
