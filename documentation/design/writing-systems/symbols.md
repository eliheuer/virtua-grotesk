# Symbols and image-derived construction

Choose the method from the geometry. Use construction from green symbols
for line-grammar symbols; use the existing img2bez masters workflow for organic
image tracing. A chosen reference image supplies the authorized form; green Virtua
sources supply construction, scale and weight unless the user specifies otherwise.

Historical symbol lessons have individual correction records. Their measured values
are revision-specific; confirm current axis, strokes, spacing and donor grades.
For @ retain the smaller italic a and double spiral; the applied candidate is still
visually rejected and awaits human correction.

The historical symbol generator now emits standalone purple GLIFs only under an
explicit fresh out/ directory. Its old measured recipes retain their original
coordinates, so generation does not imply draft-grid compliance. Inspect/refit and
register into a scratch font before building; no active installation is performed.

## Glyph decisions

- dollar uses the uppercase S as its body (7f8be952).
- section needs chamfer terminals; it is orange because the trace is light
  (22ccd03a).
