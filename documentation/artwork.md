# Artwork

README and social image scripts live alongside their intended outputs in
`documentation/readme-images/` and `documentation/social-assets/`. The current
article draft is text-only; its specimen selection is still pending.

The old `assets/image-license.txt` contained a provenance note, not a license
grant. It described earlier README images as rendered from Virtua Grotesk,
without third-party photographs or illustrations. Those historical filenames
are not a current release-asset manifest.

Before packaging images, confirm which files are project-owned and approve
their license. Keep third-party references outside any blanket artwork grant.
Google Fonts requests CC BY-SA 4.0 for submitted artwork and specifies image
sizes/formats in its [article guide](https://googlefonts.github.io/gf-guide/article.html).
Image-license approval remains pending; the font's OFL is unchanged.
