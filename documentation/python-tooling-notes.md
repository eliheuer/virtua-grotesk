# Python Tooling Notes

This repo keeps a small top-level dependency list for the local Google Fonts
build and report workflow.

## Files

- `requirements.in` lists direct Python packages used by the repo.
- `requirements.txt` is the pinned install snapshot used by
  `pip install -r requirements.txt`.

The official Google Fonts project template uses `requirements.in` plus a pinned
`requirements.txt` generated by `pip-compile`. Virtua Grotesk keeps the same
two-file shape, with `requirements.txt` pinned from the active local .venv for
this onboarding pass. If the Python toolchain changes, update
`requirements.in` first, reinstall in a clean .venv, regenerate the pinned
snapshot, then rerun `make preflight`.

## Direct Python packages

- `fontmake`: installed because it is part of the Google Fonts builder stack.
- `fonttools`: generated-font metadata reports and metadata patching.
- `gftools[qa]`: Google Fonts builder, downstream Packager, and
  `gftools qa --proof` visual proof tooling for spacing and kerning review.
- `GitPython`: required by `gftools packager`.
- `glyphsets`: Google Fonts Latin and Arabic glyphset coverage reports.
- `PyYAML`: local preflight validation of `sources/config.yaml`.
- `uharfbuzz`: Arabic shaping smoke tests.

## External tools

- Fontspector is installed outside pip, currently with Cargo, and is the active
  automated Google Fonts QA entrypoint. The local QA scripts use the normal
  `~/.fontspector` directory and still pass `--skip-network` so report
  generation stays local and repeatable.
- designbot PDF proofing is the active local visual QA path. Use
  `make proof` and `make specimen` after builds and before final handoff,
  especially when spacing or kerning changes.
Some transitive packages in the local virtual environment may include older
tooling names such as `fontbakery`. Those are not project entrypoints. Use
Fontspector for Google Fonts QA. Older Google Fonts upstream/template
automation references may still mention FontBakery, so do not replace the local
Fontspector workflow unless a reviewer requests a specific legacy check.

To refresh the pinned snapshot after an intentional toolchain update:

```bash
./.venv/bin/python -m pip freeze --all > requirements.txt
make preflight
```
