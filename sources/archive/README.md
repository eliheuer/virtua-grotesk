# Source Archive

This directory contains older Virtua Grotesk and Kinderhugel Grotesk source
snapshots kept for reference.

These files are not active Google Fonts build inputs. The active source set is
listed in `../README.md` and is limited to:

- `../VirtuaGrotesk.designspace`
- `../VirtuaGrotesk-Regular.ufo`
- `../VirtuaGrotesk-Bold.ufo`

Do not package files from this archive into the downstream `google/fonts` pull
request unless a reviewer explicitly asks for historical source material.
