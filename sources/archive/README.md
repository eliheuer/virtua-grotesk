# Source Archive

This directory contains older Virtua Grotesk and Kinderhugel Grotesk source
snapshots kept for reference.

These files are not active source inputs. The active source set is listed in
`../README.md` and is limited to:

- `../VirtuaGrotesk.designspace`
- `../VirtuaGrotesk-Regular.ufo`
- `../VirtuaGrotesk-Bold.ufo`

Do not package or build from this archive unless a maintainer explicitly asks
for historical source material.
