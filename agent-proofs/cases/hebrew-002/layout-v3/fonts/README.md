# Frozen review fonts

These unmodified binaries are retained solely to reopen the HEB-002 comparison.
`../live-fonts.json` records each role, filename and SHA-256; `../snapshot.json`
is the portable preparation manifest. `labels.ttf` is an identical copy of Applied.

- Virtua Before and Applied: local reviewed builds, licensed under `Virtua-OFL.txt`.
  Their build identities and original paths are in `../clean-render.json`.
  They are historical proof assets, not the current checkout's release binaries.
- Rubik: The Rubik Project Authors, https://github.com/googlefonts/rubik,
  licensed under `Rubik-OFL.txt`.
- Noto Sans Hebrew: The Noto Project Authors, https://github.com/notofonts/hebrew,
  licensed under `NotoSansHebrew-OFL.txt`.

Reference assets were retained from the original HEB-001 comparison cache;
no reference font update or binary modification is part of this preservation.
