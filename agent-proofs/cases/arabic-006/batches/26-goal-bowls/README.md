wrapper advances. The actual reference raster showed a more fundamental issue:
both supplied fonts with coverage use an open terminal. Improving our closed
bowl did not resolve that structural discrepancy. The final trial and its two
wrapper changes were withdrawn by exact baseline-byte restoration. Preserved
`rejected-final-trial-700.png`, its receipt and `assets/rejected-final-trial.ttf`

and these files are excluded from the applied target list and compiled closure.

references. Their Regular sources are green, so record a paired-master structural
proposal before redesigning them. These are not whole-family approval.
