# Feedback moved

Use the [correction library](../design/corrections/README.md) and
[current review state](../design/reviews/current.json). Record new feedback in the
current case, index reusable corrections, and update the relevant canonical rule.

The complete [feedback history through 2026-10-29](../design/reviews/history/feedback-2026-10-29.md)
is preserved as evidence. Dated queues and superseded rules there are not current
instructions. Proof-interface layout decisions remain available in that history.
