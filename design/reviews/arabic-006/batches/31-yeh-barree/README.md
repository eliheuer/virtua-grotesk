# Yeh Barree isolated and final — first-pass draft

Four files: `yehBarree-ar` and `.fina` in Regular and Bold. Before, both were
the same disconnected L-shaped drawing. Actual Noto/Plex images established
the separate isolated left return and connected final lower bowl. The isolated
draft now has an angled chamfered terminal and baseline return, width960; final
has a returning lower bowl and a true104/176 incoming join, width704. The head
is deliberately angular, unlike Noto's hooked top and Plex's short upright.
That stylistic simplification and the generous isolated width need human review.

Whole-image endpoint/intermediate rows, enlarged endpoints and joined carriers
were inspected. Curves show no sampled reversals or tangent kinks; inherited
G1 curvature jumps are recorded, and sampled intersections are zero at five
weights. Both masters match in22/20point contours. Thirty compiled shaping
comparisons preserve substitutions/clusters/mark offsets and limit ink/advance
changes to these two glyphs. Preflight passed in the exact scratch source tree.
No external outlines were copied. Shared components have no consumers here.
All34 Beh/Heh reservations, green sources and manual hamza remain unchanged.

Rubik/Readex lack U+06D2 and are explicitly unavailable. Noto/Plex supply actual
comparisons. Full-source hashes and exact before/candidate files are retained.
Twelve grid findings are unchanged anchors; all new points/advances are on8.
The old top anchor832,320 is misplaced (beyond the final advance), and bottom
anchors also need the dedicated attachment pass. These are not resolved.
This is a purple working draft for manual editing, not visual approval.
